## Что делаем (2 вечера)
Небольшое, но "senior-грамотное" приложение на **React + TS + GraphQL** (их nice-to-have).

Стек-кандидат:
- React 18/19 + TypeScript (strict)
- Vite
- GraphQL: Apollo Client ИЛИ urql (публичное API — GitHub GraphQL / Rick&Morty / SpaceX)
- Роутинг: React Router
- Состояние: TanStack Query (если REST) либо кэш Apollo; Zustand при нужде
- CSS: без UI-кита, руками — показать адаптив/семантику (их требование "CSS и адаптив")
- Тесты: Vitest + Testing Library (показать инженерную зрелость)
- ESLint + типы строгие

Идея приложения (выбрать одну) — два фаворита:
- [ ] **Rick&Morty каталог** (GraphQL API rickandmortyapi.com): список персонажей, фильтры (статус/вид), поиск, карточка детали, избранное (localStorage), пагинация, адаптив. Плюс: готовая публичная GraphQL-схема, богатые данные, легко показать фильтры+пагинацию+кэш.
- [ ] **GraphQL-дашборд** (GitHub GraphQL API): дашборд по репо/юзеру — метрики, звёзды, языки, графики, live-запросы к GitHub GraphQL. Плюс: реальный auth-токен, серьёзнее выглядит, ближе к их "рефакторинг + компоненты + архитектура".
- [ ] (запас) SpaceX/иное публичное GraphQL API — если первые два надоели.

Выбор между фаворитами: Rick&Morty — быстрее и нагляднее (фильтры/пагинация/кэш из коробки); GitHub-дашборд — солиднее для senior-резюме (графики, auth, метрики). Решаем на старте.
